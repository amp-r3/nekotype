# ADR 095: `/type` Answers 404, and the Browser Tests and the Latency Gate Move to Recall

- **Status:** In force; point 5 amended by [ADR 096](096-learning-only-data-and-sync-format-2.md). Amends [ADR 048](048-worst-keystroke-latency-gate.md) (items 1 and 3), [ADR 052](052-e2e-scope-and-latency-on-main.md) and [ADR 074](074-latency-gate-on-pull-requests-that-can-move-it.md) (what the latency test types and which files make it necessary) and the report dialog of [ADR 092](092-report-dialog-turnstile-keys-by-host-and-fail-closed-secret.md) (the client part).
- **Context:** [ADR 093](093-learning-only-words-in-learning.md) removes the typing trainer, and the first pull request of phase P6 ([p6-plan.md](../archive/p6-plan.md), PR 1) takes the screen out of the code. Three things depended on it beyond the screen: the routes and the navigation, the browser tests of the input source and of keystroke latency, which all typed on `/type`, and the hot-path render test. Recall (the typing task of a learning session) uses the same input source, so what those tests proved stays worth proving there.
- **Decision:**
  1. **`/type` is not redirected.** It leaves `ROUTE_PATHS`, the routes, the title switch, the idle prefetch and `public/_redirects`, and answers 404 with the static not-found page, as `/learn` does since P3 ([ADR 077](077-static-404-page.md)). The deployment smoke test expects 404 for `/type` and for `/learn`. The navigation is `learn · stats · settings`.
  2. **The idle prefetch** loads the routes, the session runtime, the session summary and both dictionaries. It no longer loads content chunks or a results panel, and takes no settings.
  3. **The input source keeps what recall uses.** The key rules that only the typing screen used go with their tests: `Ctrl/Cmd+Enter` as a `finish` intent (a modifier combination now always belongs to the browser) and the activity callback that fed the idle end of a test. Behaviour on recall does not change.
  4. **The browser tests of input move to recall.** The layout notice (a Cyrillic key, `beforeinput` text, a key pressed on a button), the keys that belong to the browser and the five IME composition tests run on a review session of one due kana, which is always a recall task. "Does not start the test" became "is not taken as an answer": the buffer stays empty, the kana is not marked and the session has not moved. The `Ctrl+Enter` test runs on the "leave session" button, because the navigation is not drawn during a session and there is no link to press it on. The WebKit project keeps the `@mobile` tests: the learning session by tap, whose recognition choices are tapped, and the layout notices on recall.
  5. **The latency test is the recall test.** Two sessions of 25 tasks under 4× throttling, the p95 and the worst keystroke against the existing budgets and ceilings. The Words and Phrases tests go. The gate's path list ([ADR 074](074-latency-gate-on-pull-requests-that-can-move-it.md)) loses `features/training/` and the trainer files and gains `pages/learn/` (tests, styles and documents still never count), `shared/ui/kana-task.tsx` and `shared/ui/task-controller.ts`. `entities/prompt/` stays: it holds the engine binding.
  6. **The render-isolation rule** is checked by `session-screen.test.tsx`; the trainer's copy and the keystroke render test of `App` are deleted.
  7. **The sync e2e are rewritten on learning**: a guest's session reaches the account and shows on a new device; a session answered offline arrives when the network returns (the first session is played online so that the lazy chunks of the session and its summary are loaded); two tabs each finish a session and both are counted once. They read the `stats-sessions` line of `/stats`; the pull request that redraws `/stats` keeps that test id.
  8. **The report dialog leaves the client** with the trainer: the dialog, its Turnstile loader and the site keys go, `POST /api/reports`, its table and the secrets stay, and P10 brings the dialog back for word tasks.
- **Justification:**
  - _Same path, same proof._ Latency of a keystroke is the work of the input source and of the task controller; recall exercises both. A budget that is no longer measured would stop meaning anything.
  - _Delete with the last consumer._ The key rules and the activity callback have no caller left; keeping them for a later phase would leave code that no test of a real screen covers. P10 restores what it needs from git history.
  - _No redirect._ Nobody but the maintainer has a link to `/type`, and a redirect would be one more rule for the smoke test and `_redirects` to keep.
- **Consequences:**
  - The initial JS fell from 32.65 to 31.68 KB and the initial CSS from 8.83 to 7.96 KB gzip; the `trainer`, `report-dialog` and `results-panel` chunks and the `type` dictionary part are gone, and the word and phrase chunks are no longer reachable from the code, so `dist` holds no word chunk (the phrase credits chunk of `/about` stays until PR 2).
  - Left to later pull requests of the phase, as the plan says: the typing store, the typing section of `/stats` and `PersonalBestBadge` that it uses (PR 3), the settings `typing` block and the typing data (PR 4), the content loaders and `/about` credits (PR 2).
  - `docs/architecture/training-session.md` is deleted.
