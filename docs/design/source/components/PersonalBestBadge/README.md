# PersonalBestBadge

The personal best mark: `personal best` / `личный рекорд`, next to the KPM label on typing results and in the history row on `/stats`. Replaces confetti (Q16).

- `eye` outline in `stroke-hair`, `eye` text, `ui-caption`, `radius-xs`. No fill: the accent takes no area.
- On results it comes with the `content` cat and the line `+3 vs previous best (101)` / `+3 к прежнему рекорду (101)`.
- A personal best is possible only for a test that ended normally — not by inactivity, not by a hidden tab, not by a manual zen finish — that is not a repeat and has kana accuracy ≥ 80%.
- Personal bests are kept per key "content · script · strictness · mode": `words · hiragana · relaxed · 60 s`.
