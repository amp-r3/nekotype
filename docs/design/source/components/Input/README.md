# Input

A form field: the deletion confirmation; `Textarea`, its multi-line form, the comment of the report dialog (decision 167). Answers in a learning task are not a field: `KanaTask` draws them.

- `bg-raised`, no border, `radius-sm`, `control-h` height; browser caret `eye`.
- In a `Dialog` (decision 127): the full width of the body and filled with `bg`, since the dialog itself is `bg-raised`.
- Placeholder — `fur-dim` (Q25): `untyped` is allowed only from 24px.
- Error — a `miss` underline at the bottom and `miss` text. Disabled — no fill, `line` border.
- `Textarea`: the same field, three lines (88px), resizable vertically, `space-2` `space-3` padding; the label over it as `Input`'s.
