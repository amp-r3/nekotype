# Pagination

History pages: `← newer · 1 2 … 12 · older →` / `← новее · 1 2 … 12 · старше →`. Phrase authors on `/about`: `← previous · 1 2 … 17 · next →` / `← назад · 1 2 … 17 · далее →`, 25 rows a page, `aria-label` `phrase list pages` / `страницы списка фраз` (decision 99).

- Items in `Segmented` style: the current page — `fur` + `eye` underline, `aria-current="page"`. Edge buttons are disabled at the edges.
- The first, last and neighbouring pages are shown; "…" replaces the rest.
