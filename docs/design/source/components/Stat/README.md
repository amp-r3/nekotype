# Stat

A metric: label, number, unit, an optional note.

- `mono-stat` number in `fur`, `ui-caption` label and unit in `fur-dim`. On `/stats` (decision 137): the totals row — `mastered · hiragana` / `освоено · хирагана` `7` `of 104` / `из 104`, the same for katakana, `sessions started` / `сессий начато`, `sessions finished` / `сессий закончено`; one per column of the page grid. The current streak is not a `Stat`: it is the large number next to the activity map.
- **No colour judgement:** the number is always `fur`, never green or `miss`.
- One size.
