# Segmented

Segmented choice: track, the blocks of the path, period, strictness, language.

- No fills: `fur-dim` → hover `fur` → selected `fur` + `eye` underline.
- `role="radiogroup"`, ← → arrows within a group, `Tab` between groups. `label` is required.
- Numbers and romaji — `mono`. Height from `touch-min` under `pointer: coarse`.
- One size. The blocks of the path (decision 155) are its one item with two lines: the block's first kana over its name and count, a `→` between items; the item's height follows them.
