# Kbd

A key in text: `esc`, `enter`, `1`–`4`.

Where the learning session shows keys: `esc` + `show the romaji` in the hint line of recall; `1`–`4` on each `OptionCard` on desktop (number row and numeric keypad both work; hidden under `pointer: coarse`); `enter` + `next` after a wrong option; `enter` on `continue` in the session summary. Under `pointer: coarse` a key with no on-screen equivalent (`esc`) is replaced by a text button, not shown.

- `mono-small`, `fur-dim`, `stroke-hair` `line-strong` border, `radius-xs`. Lower-case labels, as on the keyboard.
- Inside a button — `bare` (no border); `Button hint` does this itself.
- Keys pressed **together** are joined with " + " (`shift + tab`); keys pressed **in turn** with " → ". `→` is in both subsets (ADR 034). Never "then" / «затем».
