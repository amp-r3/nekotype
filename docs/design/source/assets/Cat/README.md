# Cat

Ten cat drawings: `cat-<style>-<mood>.svg`, viewBox 96×96. The product uses `geometry` only (`neutral`, `sleep`, `content`); `cat-geometry-grumpy.svg` is drawn but not placed yet (decision 98). The `line` and `silhouette` files are an archive and are not used in the product.

- Colours are baked in: fur `#efe9dd` (`fur`), eyes `#a5c8dd` (`eye`), cut-outs `#1c1e21` (`bg`). Place on `bg` only.
- In the interface use the `Cat` component: it takes its colours from tokens. The files are for places outside the app (OG images, README, social media).
